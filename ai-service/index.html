伴奏分离 Inst HQ 3

基于 UVR-MDX-NET-Inst_HQ_3 模型，本地 CPU 处理。拖入音频即可提取伴奏与人声；拖入视频可提取并合并伴奏音轨。
拖入音频或视频文件，或点击选择 音频：WAV / MP3 / FLAC / M4A 等；视频：MP4 / MKV / AVI / MOV / FLV / WEBM 等（自带 ffmpeg，无需另外安装）
已识别为视频文件 — 视频音轨处理方式
分离出的伴奏音轨将按原视频音轨格式重新编码后合并进视频。

分离完成，选择下载：

视频预览（切换Tab对比原唱 / 伴奏）

调试 / 本地路径导入
供调试与自动化测试：直接指定服务器本地文件路径创建任务，无需经浏览器上传。
使用说明：① 双击文件夹内的「启动.vbs」自动打开本页（或双击 start.bat）；② 拖入歌曲；③ 跟随进度条观察处理；④ 下载伴奏/人声（16-bit WAV）。 注意：请务必通过「启动.vbs / start.bat」打开本页（地址栏为 http://127.0.0.1:8900/），不要直接双击 index.html 文件——那样页面会因浏览器安全限制无法与本地服务通信。 单乐曲 CPU 处理约耗时数分钟，属正常现象。所有文件仅在本地处理，不会上传任何服务器。
